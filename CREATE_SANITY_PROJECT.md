# Создание нового проекта Sanity через веб-интерфейс

## 🌐 Шаг 1: Создание нового проекта

1. Перейдите на **https://www.sanity.io/manage**
2. Нажмите кнопку **"Create new project"** или **"+ New project"**
3. Введите название проекта: **ELBIKO**
4. Выберите план: **Free** (бесплатный)
5. Нажмите **"Create project"**

## 📝 Шаг 2: Настройка проекта

После создания проекта:

1. Скопируйте ваш новый **Project ID** (он будет показан на экране)
2. Обновите файлы конфигурации:

### Обновите `src/sanity/env.ts`:
Замените `projectId` на ваш новый ID

### Обновите `.env.local`:
Замените `NEXT_PUBLIC_SANITY_PROJECT_ID` на ваш новый ID

### Обновите `sanity.config.ts`:
Замените `projectId` на ваш новый ID

## 🎨 Шаг 3: Настройка схем данных

После создания проекта:

1. В Sanity Manage выберите ваш проект ELBIKO
2. Перейдите в **Settings** → **API** → **Datasets**
3. Убедитесь, что dataset `production` существует
4. Если нет, создайте его

## 📋 Шаг 4: Импорт схем данных

У вас уже есть созданные схемы данных в `src/sanity/schemaTypes/`. Чтобы использовать их в облачном редакторе:

### Вариант А: Использовать Sanity Desk (рекомендуется)

1. В Sanity Manage перейдите в **Settings** → **Studio**
2. Нажмите **"Create Studio"**
3. Выберите **"From existing schemas"** или **"Custom"**
4. Скопируйте содержимое файлов из `src/sanity/schemaTypes/` в веб-редактор схем

### Вариант Б: Использовать Sanity Content Lake напрямую

Если Sanity Desk недоступен, можно использовать Sanity Content Lake напрямую через API.
