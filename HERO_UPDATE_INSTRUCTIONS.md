## Как добавить фото Wenbox U6

### 1. Подготовьте изображение
- Найдите качественное фото Wenbox U6
- Рекомендуемый размер: минимум 800x600px
- Форматы: JPG, PNG, WebP
- Оптимизируйте изображение (можно через TinyPNG или Squoosh)

### 2. Создайте папку для изображений
Если папки нет, создайте её:
```
public/images/
```

### 3. Положите файл
Сохраните фото как `wenbox-u6.jpg` в папку `public/images/`:
```
public/images/wenbox-u6.jpg
```

### 4. Проверьте работу
- Обновите страницу http://localhost:3000
- Фото должно появиться справа в Hero секции
- Если фото не появляется, проверьте консоль браузера на ошибки

## Как настроить контактные данные

### Через базу данных (Prisma Studio):
```bash
npx prisma studio
```
Откройте таблицу `Hero` и обновите поля:
- `phone` — ваш телефон
- `telegramUrl` — ссылка на ваш Telegram
- `whatsappUrl` — ссылка на ваш WhatsApp

### Через SQL:
```sql
UPDATE hero 
SET phone = '+7 (999) 123-45-67',
    telegramUrl = 'https://t.me/your_telegram',
    whatsappUrl = 'https://wa.me/79991234567'
WHERE id = 1;
```

### Через seed-файл:
Отредактируйте `prisma/seed-content.ts` и запустите:
```bash
npm run seed-content
```
