# Как добавить изображения на сайт

## Способ через базу данных (рекомендуется)

### 1. Подготовка изображений
- Поместите ваши изображения в папку `public/images/`
- Рекомендуемые форматы: JPG, PNG, WebP
- Рекомендуемые размеры:
  - Hero фон: 1920x1080px
  - Карточки (тарифы, преимущества): 400x300px
  - Шаги: 400x300px

### 2. Обновление контента через базу данных

У вас есть несколько способов управления контентом:

#### Через админ-панель (если есть)
Откройте админ-панель и отредактируйте записи в таблицах:
- `hero` - главная секция
- `feature` - преимущества  
- `step` - шаги "как это работает"
- `tariff` - тарифы

#### Через SQL напрямую
```sql
-- Обновить фоновое изображение Hero
UPDATE hero SET backgroundImageUrl = '/images/your-hero-bg.jpg' WHERE id = 1;

-- Обновить изображение преимущества
UPDATE feature SET imageUrl = '/images/your-feature.jpg' WHERE id = 1;

-- Обновить изображение тарифа
UPDATE tariff SET imageUrl = '/images/your-tariff.jpg' WHERE id = 1;
```

#### Через Prisma Studio
```bash
npx prisma studio
```
Откроется интерфейс для редактирования данных в базе.

#### Через seed-файл
Отредактируйте `prisma/seed-content.ts` и запустите:
```bash
npm run seed-content
```

### 3. Текущая структура путей к изображениям

В базе данных сейчас установлены следующие пути (заглушки):
- Hero: `/images/hero-bg.jpg`
- Преимущества: `/images/feature-*.jpg`
- Шаги: `/images/step-*.jpg`
- Тарифы: `/images/tariff-*.jpg`

### 4. Как это работает

1. Сайт загружает данные из базы данных через функции в `src/lib/contentQueries.ts`
2. Если данные есть в БД - используются компоненты с суффиксом `DB` (например, `HeroDB`)
3. Если данных нет - используются обычные компоненты с эмодзи (например, `Hero`)
4. Изображения загружаются через Next.js Image компонент с оптимизацией

### 5. Пример добавления изображения

1. Положите файл `my-bike.jpg` в папку `public/images/`
2. Обновите запись в базе:
```sql
UPDATE bike SET imageUrl = '/images/my-bike.jpg' WHERE id = 1;
```
3. Изображение автоматически появится на сайте

## Преимущества этого подхода

✅ **Простота** - не нужно настраивать Sanity или другие CMS  
✅ **Быстрота** - изображения хранятся локально, загружаются мгновенно  
✅ **Контроль** - полный контроль через базу данных  
✅ **Fallback** - если изображения нет, показывается эмодзи  
✅ **Оптимизация** - Next.js автоматически оптимизирует изображения  

## Следующие шаги

1. Добавьте ваши изображения в папку `public/images/`
2. Обновите пути в базе данных через Prisma Studio или SQL
3. Проверьте результат на сайте
