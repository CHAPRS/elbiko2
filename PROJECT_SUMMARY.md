## 📋 Текущее состояние проекта

### Технологии:
- Next.js 14.2.0 с TypeScript
- Prisma для базы данных
- Tailwind CSS для стилей
- Zustand для state management
- React Hook Form для форм
- Telegram бот для уведомлений

### Цветовая схема:
- Основной фон: slate-950 (темный)
- Акцентные цвета: emerald-400, cyan-400 (зеленый/циановый)
- Текст: slate-100, slate-400, slate-500

### Функциональность:
- Лендинг с современным дизайном
- Каталог велосипедов
- Система тарифов
- FAQ секция
- Адаптивный дизайн
- Мобильное меню

## 🚀 Запуск проекта

### 1. Установка зависимостей:
```bash
cd C:\xampp\htdocs\ebike-rent
npm install --legacy-peer-deps
```

### 2. Запуск dev сервера:
```bash
npm run dev
```

### 3. Открытие сайта:
```
http://localhost:3000
```
