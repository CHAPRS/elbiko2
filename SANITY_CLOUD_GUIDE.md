## 🔗 Подключение компонентов к Sanity

После создания контента в Sanity Desk, выполните следующие шаги:

### 1. Замените импорты в `src/app/page.tsx`:

Замените:
```typescript
import Hero from '@/components/Hero';
import Tariffs from '@/components/Tariffs';
```

На:
```typescript
import HeroSanity from '@/components/HeroSanity';
import TariffsSanity from '@/components/TariffsSanity';
```

### 2. Замените компоненты в JSX:

Замените:
```tsx
<Hero />
<Tariffs />
```

На:
```tsx
<HeroSanity />
<TariffsSanity />
```

### 3. Перезапустите Next.js:
```bash
npm run dev
```

## ✅ Проверка

После переключения на Sanity компоненты:
- Загрузят данные из Sanity CMS
- Если данные недоступны, покажут статические данные (fallback)
- Будут автоматически обновляться при изменении контента в Sanity Desk

## 🎯 Преимущества этого подхода:

✅ **Не требует установки npm** - работает через браузер  
✅ **Полнофункциональный редактор** - все возможности Sanity Studio  
✅ **Автоматическое сохранение** - контент сохраняется в облаке  
✅ **Fallback на статические данные** - сайт работает даже без CMS  
✅ **Простое переключение** - легко включить/выключить CMS интеграцию
