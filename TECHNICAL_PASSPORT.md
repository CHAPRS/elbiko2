# Технический паспорт проекта ELBIKO
## Аренда электровелосипедов для курьеров

**Дата создания:** 05.08.2026  
**Статус проекта:** Активная разработка  
**Технологический стек:** Next.js 14.2.0, TypeScript, Prisma, Tailwind CSS

---

## 📋 Общее описание проекта

**Назначение:** Сайт аренды электровелосипедов для курьеров в Красноярске  
**Целевая аудитория:** Курьеры сервисов доставки (Яндекс Еда, Самокат, Купер)  
**Основные функции:** Каталог велосипедов, система тарифов, бронирование, управление парком

---

## 🏗️ Текущая реализация

### 1. Стек технологий

**Frontend:**
- Next.js 14.2.0 (App Router)
- React 18.2.0
- TypeScript 5.9.3
- Tailwind CSS 3.4.1
- Zustand 4.5.1 (state management)
- React Hook Form 7.50.1 (forms)

**Backend:**
- Next.js API Routes
- Prisma 6.19.3 (ORM)
- PostgreSQL (через Prisma)
- Nodemailer 9.0.3 (email)

**Интеграции:**
- Telegram бот (уведомления)
- Sanity CMS (подготовлена, не активирована)
