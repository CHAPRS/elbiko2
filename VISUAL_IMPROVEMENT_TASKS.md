# Задачи по улучшению визуальной части главной страницы

## 🎨 Текущее состояние
- Сайт использует темную цветовую схему (slate-950, slate-900)
- Основные цвета: emerald-400/cyan-400 для акцентов
- Есть структура секций, но многие элементы используют эмодзи вместо изображений
- Реализована система управления контентом через базу данных

## 📋 Задачи по улучшению визуальной части

### Высокий приоритет

#### 1. Добавление реальных изображений
**Цель:** Заменить эмодзи на качественные фотографии для создания визуального appeal

**Задачи:**
- [ ] Создать папку `public/images/` и подпапки для категорий
- [ ] Подготовить изображения для Hero секции (фоновое изображение курьера на электровелосипеде)
- [ ] Подготовить изображения для 6 преимуществ (фото АКБ, сервиса, документов и т.д.)
- [ ] Подготовить изображения для 4 шагов "как это работает"
- [ ] Подготовить изображения для 3 тарифов (фото велосипедов разных категорий)
- [ ] Обновить пути в базе данных через Prisma Studio

**Рекомендации по изображениям:**
- Hero фон: 1920x1080px, реальные фото курьеров
- Карточки: 400x300px, качественные фото деталей
- Форматы: WebP (приоритет), JPG, PNG
- Оптимизация через Next.js Image компонент уже настроена

#### 2. Улучшение Hero секции
**Цель:** Сделать главный экран более привлекательным и конверсионным

**Задачи:**
- [ ] Добавить реальное фоновое изображение курьера на электровелосипеде
- [ ] Улучшить градиентный оверлей для лучшей читаемости текста
- [ ] Добавить анимацию появления элементов (fade-in, slide-up)
- [ ] Улучшить типографику заголовка (размеры, отступы)
- [ ] Добавить параллакс эффект для фонового изображения
- [ ] Добавить видео-фон как опцию (автоплей, mute, loop)

#### 3. Оптимизация карточек тарифов
**Цель:** Сделать тарифы более привлекательными и понятными

**Задачи:**
- [ ] Добавить реальные фото электровелосипедов для каждого тарифа
- [ ] Улучшить визуальное выделение популярного тарифа
- [ ] Добавить hover-эффекты с анимацией
- [ ] Улучшить отображение списка преимуществ (иконки вместо точек)
- [ ] Добавить "shine" эффект на популярном тарифе
- [ ] Улучшить мобильную адаптацию карточек

## 🚀 Рекомендуемый порядок выполнения

1. **Начать с:** Задача 1 (Добавление реальных изображений) — даст максимальный визуальный эффект
2. **Продолжить:** Задача 2 (Улучшение Hero секции) — первое впечатление
3. **Затем:** Задача 3 (Оптимизация карточек тарифов) — конверсия
4. **Параллельно:** Задачи 4-7 — улучшение отдельных секций
5. **Финал:** Задачи 8-10 — полировка и детали

## 📊 Метрики для измерения успеха

- Время загрузки изображений (Lighthouse Performance)
- Конверсия на тарифах (клики на "Выбрать тариф")
- Время нахождения на странице (Analytics)
- Отзывы пользователей (UX testing)
- Accessibility score (Lighthouse)

## 🛠️ Инструменты для работы

- **Изображения:** Adobe Photoshop, Figma, Canva
- **Оптимизация:** TinyPNG, Squoosh, Next.js Image
- **Анимации:** Framer Motion, CSS animations
- **Типографика:** Google Fonts, Font Squirrel
- **Цвета:** Coolors, Adobe Color, Contrast Checker

## 📝 Примечания

- Все изменения должны быть мобильно-адаптивными
- Учитывать Accessibility (WCAG 2.1 AA)
- Тестировать на разных устройствах и браузерах
- Сохранять текущую функциональность при визуальных изменениях
- Использовать существующую систему управления контентом через БД
